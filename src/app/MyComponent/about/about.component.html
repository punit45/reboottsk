This TODO App is a simple yet effective task manager built using Angular and Bootstrap. The app allows users to add, mark as done/undone, and delete tasks, with all data being stored locally in localStorage instead of a backend server.

Key Features:

  • Add a TODO – Enter a title and description to create a new task.
  • Mark as Done/Undone – Click to toggle the task's completion status.
  • Delete a TODO – Remove tasks from the list.
  • LocalStorage Integration – Persist data without a backend.
  • Dynamic UI – Used ngClass, ngFor, and ngIf for rendering.
  • Routing – Implemented basic navigation with Angular routing.

Tech Stack Used:

  • Angular – Component-based UI and state management.
  • Bootstrap – Responsive styling and layout.
  • LocalStorage – Stores tasks persistently without a server.
